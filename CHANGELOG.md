# Changelog

## [0.1.1]

First release from the recreated public repository. Runtime contract remains 0.1.

- Use public HTTPS installation without deploy keys.

- Adopt ESLint and Prettier and enforce both in CI.
- Reorganize documentation and remove obsolete implementation-history commentary.

- Add a standalone laboratory template with a pinned SDK, MIDI-learn, tests and agent instructions.
- Verify the template in CI against the candidate SDK archive.

## 0.1.0 (previous private repository)

First packaged release of the existing SDK. No runtime API changes.

- Runtime contract 0.1: per-instance state, parameters, actions, layout and lifetime.
- Accessible UI, canvas plotting, PCM, AudioWorklet and Web MIDI.
- Separate production, testing and CSS exports.
- CI verification and GitHub Release archives with SHA-256 checksums.
- Fresh-consumer archive and Git installation smoke tests and installation/release documentation.
